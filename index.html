Model Technical Specs

1. Regime Filter

SMA50 > SMA200 (Golden Cross regime). Screens out assets in long-term structural downtrends.

2. Momentum Filter

MACD (12, 26, 9) > 0. Validates accelerating intermediate upside velocity.

3. Value / RSI Filter

RSI(14) < 70. Rejects short-term overbought exhaustion points.

4. Inverse Volatility

Calculates historical daily return volatility (σ). Weight $w_i = \frac{1/\sigma_i}{\sum 1/\sigma_j}$, optimizing risk contribution across survivors.
